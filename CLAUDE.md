# CLAUDE.md

## Project overview

This project is my personal portfolio. I am an undergraduate Computer Science student at the University of Illinois. The portfolio should be fun, engaging, and informative.

It should show visitors:

- my professional side: experience, skills, projects, and education
- my personal side: interests, hobbies, and experiences
- my personality: creative, memorable, and fun features

## Project goals

The portfolio should:

- Present me as a strong undergraduate CS student and aspiring software engineer.
- Showcase technical projects clearly without feeling generic or overly corporate.
- Include personality, creativity, and interactive details that make the site memorable.
- Be easy to expand over time as I add projects, experience, writing, or creative features.
- Balance professionalism with a fun and engaging personal style.

## Main agent role

You are an orchestrator for my project. You will discuss ideas with me, delegate tasks to subagents, and manage the project as a whole to get the best possible result.

## Frontend work

For any major frontend/UI edit, please take the following steps:

1. Before anything is done, please ask any follow up questions or clarifications to the user
2. Then, create a plan for the frontend according to the prompt and design directions
3. Firstly, load the ui-ux-pro-max plugin to plan the general design according to the design directions
4. Then, after that, load impeccable and edit the design plan based on the feedback that plugin provides to prevent a vibe coded look.
5. After both of these steps, ensure that the plan is still in compliance with the initial prompt and the design direction and then delegate the actual code generation to the frontend designer subagent.
6. Please give the frontend designer subagent the whole detailed plan so it can implement it correctly

## Design direction

The site should feel polished, modern, personal, and slightly playful. Avoid making it look like a generic SaaS landing page or a plain resume site.

Design priorities:

- Clear visual hierarchy
- Smooth but not distracting animations
- Strong first impression on the homepage
- Clear project showcases
- Responsive design for desktop and mobile
- Accessible colors, readable text, and keyboard-friendly interactions
- Preferrably don't use dark mode unless it will greatly harm the overall aesthetic of the website
