Project demo media goes here. Each project card uses these conventions:

  public/projects/<slug>.mp4   - autoplay-on-hover demo (muted)
  public/projects/<slug>.jpg   - optional poster image

Slugs currently expected by the gallery:

  friendly-fineprint
  systems-projects
  ubermate
  runbuddies
  annotated-iliad
  portfolio

If a file is missing the card falls back to a typographic placeholder with the project title set huge. No code changes required to add or remove videos.
